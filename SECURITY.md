# Security Policy

## Supported versions

Only the latest release on PyPI receives security fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **mattekudacy@gmail.com** with:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof of concept
- The `triage-agent` version affected

You will receive a response within 72 hours. If the vulnerability is confirmed, a patched release will be published and credited to you (unless you prefer to remain anonymous).
